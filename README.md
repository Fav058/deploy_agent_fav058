# Student Attendance Tracker Deployment Agent

## Project Overview

This project implements a Bash-based deployment agent for a Student Attendance Tracker.

The deployment agent provides three main features:

1. Deploy application
2. Run application
3. Archive logs

## Requirements

The system requires:

- Bash
- Python 3
- zip
- Git
